SDK araçları
            
            
            
Workflow UUID girin (görüşme trigger UUID’si değil). Yayın, bu workflow’un SDK araç kataloğunu robotun güncel araçlarıyla değiştirir. Görüşme açılmaz.

            
            

          

          
Yankı engelleme · AEC
            
            
            
PipeWire WebRTC AEC modülü

            
            
Düşük frekanslı motor uğultusunu azaltır. Açık önerilir; kapatmak daha dolgun bas bırakır fakat uğultu ve yankıyı artırabilir.

            
AEC içindeki ek sabit gürültü azaltmadır. Açık ortam gürültüsünü düşürür; çok hafif konuşmada yapaylık oluşturursa kapatılabilir.

            
Mikrofon düzeyini yükseltir. Sessiz kullanıcıyı güçlendirebilir ama motor ve yankıyı da büyütebilir; varsayılan kapalıdır.

            
Uzun veya karmaşık yankı yollarında daha iyi uyum sağlar. Açık önerilir; kaynak sınırlıysa kapatmak CPU yükünü azaltabilir.

            
Değişken Bluetooth gecikmesini izlemeye yardım eder. Açık önerilir; sabit kablolu ses yolunda kapatmak daha kararlı olabilir.

          

          
Mikrofon akışı
            
Açıkken robot konuşurken sıfır PCM gönderilir: yankıyı önler fakat kullanıcı sesi kayda gitmez. Kapalıyken ses sürekli iletilir; çalışan AEC gerekir.

            
            
            
          

          
Söz kesme koruması
            
            
            
          

          
Verasist sunucu VAD ayarı SDK tarafından istemciye sunulmuyor. Mikrofon kontrolleri PCM sesini değiştirir; AEC modül değişiklikleri sonraki görüşmeden önce PipeWire yeniden başlatılarak uygulanır.
